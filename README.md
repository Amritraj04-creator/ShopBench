# ShopBench

## Research Project

ShopBench is an experimental research project for comparing different frameworks for developing Android applications.

The same application will be implemented using:

- Native Android
- Flutter
- React Native

The implementations will use equivalent functionality, a common backend, common dataset, and standardized workloads and experimental conditions.
